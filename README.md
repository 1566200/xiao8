# 肖八刷题 · 2027 考研政治

把《2027 肖秀荣考研政治冲刺 8 套卷》做成了一个能放在手机上随时打开的刷题网站。

纯静态页面，不用装环境、不用数据库，传上 GitHub 就能用；支持离线（PWA），加个「添加到主屏幕」就跟 App 一样。

- **264 道选择题**（8 套 × 16 单选 + 17 多选），每道都有**答案 + 原文解析**
- **40 道分析题**（34–38），参考答案折叠式展开
- **111 张考点卡片**，纯知识点模式直接背
- **肖四板块已预留**，数据一到自动上线

---

## 三种学习方式（外加几种）

### 1️⃣ 纯刷题 —— 选了答案立刻出解析
点选项 → 立刻判对错、标出正确答案、弹出解析，不用翻页对答案。
多选题选完点「确定」再判分。答错的题自动进错题本。

### 2️⃣ 纯知识点 —— 不做题，只过考点
把 264 道题里的考点抽成卡片，按模块分组。
每张卡：考点名 + 2–5 条要点 + 出处题号，点「原文解析」还能展开原书那段话。
适合考前 30 分钟快速过一遍。

### 3️⃣ 分类学习 —— 同模块的题放一起
先选模块（马原 / 毛中特 / 史纲 / 思修法治 / 时政当代），再按考点分组，一组一练。
哪个考点总错，就点进去只刷那一个。

## 怎么传到 GitHub（手机端随时打开）

### 第 1 步：建仓库
打开 <https://github.com/new>，仓库名随便写（比如 `shiba`），**Public**，不要勾选任何初始化文件，点 Create。

### 第 2 步：上传文件
在仓库页面点 **Add file → Upload files**，把本项目**里面的所有内容**（`index.html`、`css/`、`js/`、`data/`、`assets/` 等，**不要**把外层文件夹一起拖进去）全部拖进网页，点 **Commit changes**。

> 命令行也行：
> ```bash
> git init
> git add .
> git commit -m "肖八刷题"
> git branch -M main
> git remote add origin https://github.com/你的用户名/shiba.git
> git push -u origin main
> ```

### 第 3 步：开启 Pages
仓库 **Settings → Pages**：

- Source 选 **Deploy from a branch**
- Branch 选 **main**，目录选 **/(root)**
- 点 Save

等 1 分钟，地址就是：

```
https://你的用户名.github.io/shiba/
```

### 第 4 步：手机上用
1. 手机浏览器打开上面那个网址
2. iPhone：Safari 分享 → **添加到主屏幕**；安卓：Chrome 菜单 → **安装应用 / 添加到主屏幕**
3. 以后点桌面图标就能直接刷，断网也能用

> 仓库里已经带了 `.github/workflows/pages.yml`，如果你用 Actions 发布（Settings → Pages → Source 选 **GitHub Actions**），push 之后会自动部署。

## 加肖四数据（等肖四出版后）

页面已经全部适配好了，**只要往 `data/x4.js` 里填数据，不用改任何页面代码**。

打开 `data/x4.js`，按这个格式填：

```js
window.SHIBA_X4 = {
  papers: [
    {
      id: "x4-1", book: "x4", no: 1, title: "肖四 第一套",
      single: [
        {
          no: 1,
          stem: "题干……",
          options: { A: "选项A", B: "选项B", C: "选项C", D: "选项D" },
          answer: "A",
          analysis: "解析原文……",
          module: "马原",
          topic: "联系的普遍性"
        }
      ],
      multi: [ /* no 从 17 到 33，答案写成 "ABD" 这种升序连写 */ ],
      essay: [
        {
          no: 34,
          material: "材料原文……",
          question: "（1）结合材料回答问题……",
          answer: "参考答案……",
          module: "马原",
          topic: "矛盾的普遍性"
        }
      ]
    }
    // 四套就写四个对象
  ]
};
```

字段约束：
- `module` 只能是 `马原` `毛中特` `史纲` `思修法治` `时政当代`
- `answer` 单选一个大写字母，多选按字母升序连写（`ABD`，不要写成 `DBA`）
- 选择题 `no`：1–16 是单选，17–33 是多选

填完提交，手机刷新两次就能看到。刷题、分类、大题、搜索、统计都会自动带上肖四。

## 改题目 / 修错字

- 题目和解析都在 `data/papers.js`，是一个 `window.SHIBA_PAPERS = [...]` 的数组，直接搜题干关键词就能定位修改。
- 考点卡片在 `data/points.js`，结构是 `{ id, module, title, bullets: [...], refs: ["x8-1-3"], quote: "原文解析" }`。

改完提交即可，不用构建。

## 常见问题

**手机上打开是旧版本？**
Service Worker 会缓存文件。多下拉刷新一两次，或者换个浏览器标签重新打开就会更新。改了内容后如果想让所有人都拿到新版，把 `sw.js` 里的 `VERSION = 'shiba-v1'` 改成 `shiba-v2` 再提交。

**换手机了，进度怎么办？**
设置 → 导出进度 → 拿到 JSON；新手机 → 导入进度。

**点进去没反应 / 白屏？**
确认 `index.html` 和 `css/`、`js/`、`data/` 在同一层级，常见原因是只上传了 `index.html`。

**为什么大题只有 40 道？**
肖八每套 5 道分析题（34–38），8 套共 40 道。选择题才是提分重点，所以大题做成折叠式，弱化但保留。
